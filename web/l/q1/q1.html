Size of TAT #11

  • Size of TAT?
    • Each entry needs: (2 + 8) Bytes
    • # of entries : 64KB / 10 bytes = 6553
    • Size of TAT : 6553 * 2 Bytes = 12.8 KB (20%)

Size of Cluster #12

  • Let’s dedicate 1KB for TAT

  • 1KB TAT + 63KB Data Region
  • # of entries : 1KB / 2-byte = 512 entries
  • Cluster size : 63KB / 512 entries = 126 Bytes

Size of Cluster #13

  • For more memory utilization, let’s set 1 byte TAT entry
  1. Cluster Size
    • 1-byte can address 256 clusters
    • Size of TAT : 1 Byte * 256 entreis = 256 Bytes
    • Size of Cluster : (64KB - 256 Bytes) / 256 entries = 255 Bytes
  2. Size of Data Region
    • (64KB - 256 Bytes) / 64KB = 99.6%
  3. Biggest File Size
    • 64KB - 256 Bytes = 65280 Bytes
