  • What’s the role of FAT?

Fat32 Overview: Disk Layout

  • Starts with (extended) BIOS Parameter Block (E/BPB)
  • Followed by FAT (File Allocation Table)
  • Followed by Cluster

About FAT

  • Entry 0: indicating ID (ok to ignore)
  • Entry 1: indicating a special maker for the end of cluster (EOC)
  • Other special markers: e.g., 0x?FFFFFF7 for bad sectors
