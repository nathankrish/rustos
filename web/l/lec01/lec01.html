What is an operating system?

  • e.g., macOS, Windows, Linux, FreeBSD, Android, iOS, etc.
  • What does an OS do for you?
    • Abstract the hardware for convenience and portability
    • Multiplex the hardware among multiple applications (or virtualization)
    • Isolate applications to contain bugs
    • Allow sharing among applications

View 1: layered organization

  • User: applications (e.g., vi and gcc)
  • Kernel: file system, process, etc. (← often considered as an OS)
  • Hardware: CPU, mem, disk, etc.

→ OS is an Interface b/w two layers, user and hardware

View 2: consisting of core services

  • Core/system services:
    • Processes (not CPU)
    • Virtual memory (not physical DRAM)
    • File and directory (not storage like HDD or SSD)
    • Many others: users, IPC, network, time, terminals, security, etc.

→ OS provides Abstraction to applications

Example: system calls

  • Interface: applications talk to an OS via system calls
  • Abstraction: process and file descriptor
  fd = open("out", 1);      // opening a file
  write(fd, "hello\n", 6);  // reading the file's content
  pid = fork();             // creating a new process

Why is designing OS challenging?

  • Conflicting design goals and trade-offs:
    • Performant yet portable
    • Isolated yet sharable
    • Extensible yet secure
    • Compatible yet efficient

→ Open problems: sandboxing for security, scalability on manycore, etc.

Programming languages for OS development

What language is used for all commodity OSes (e.g., Linux, Windows)?

  • 1964: PL/I for Multics
  • 1969: C for Unix
  • 1995: javaOS by Sun
  • 2014: Swift for macOS (in part)

Ref. Wikipedia

Why using C for OS development?

  • Portability
  • No runtime
  • Direct hardware/memory access
  • (decent) Usability

→ Why not A, B, and C (e.g., Python, JavaScript, C++, etc)?
